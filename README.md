# ベビーシッター/ファミサポ料金シミュレーター

ワンオペ日にベビーシッターやファミリーサポートを利用する際の料金を、サービスごとの単価から自動計算するWebアプリです。

## 使い方

[GitHub Pagesで公開中のページ](https://amanosaaan.github.io/babysitter-fee-tracker/) を開くだけで使えます。インストールやログインは不要です。

## 主な機能

- サービス(ファミサポ/ベビーシッター)ごとの単価設定(ファミサポは時間制)
- 対象日をまとめて貼り付けて自動で曜日・年月を判定
- 担当者(田代さん/小林さん/田中さん など)ごとの内訳集計
- カレンダー表示(確定/予定の区別、色分け)
- 依頼メッセージの作成・コピー
- カレンダー・集計を画像として保存(LINEなどで共有用)

データはブラウザのlocalStorageに保存されます。
